# 📈 Tactical Semiconductor Dashboard

Dashboard táctico desarrollado con Python y Streamlit.

## Empresas

- AMD
- NVIDIA
- Cisco
- Lam Research
- Intel
- Broadcom
- Applied Materials
- ASML
- KLA

## Funciones

- Ranking táctico
- Score de 0 a 100
- Señales COMPRAR / MANTENER / VENDER
- Nivel de riesgo
- Filtros por empresa
- Filtros por señal
- Filtros por riesgo
- Filtro por Score mínimo
- Análisis individual
- Momentum
- Análisis fundamental
- Análisis técnico
- Catalizadores
- Estrategia de rotación de capital
- Asignación porcentual
- Estructura de fuentes

## Tecnologías

- Python
- Streamlit
- Pandas

## Restricciones

- Sin JavaScript
- Sin base de datos
