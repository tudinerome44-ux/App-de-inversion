# Trading Tactical — Streamlit (prueba)

## Probar en Windows

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Esta versión prueba la interfaz: 9 empresas, búsqueda, filtro, cinco referencias y estrategia. No consulta Internet todavía, no usa JavaScript y no usa base de datos.
